## Description
Work with Obsidian vaults using the official Obsidian CLI (v1.12+, Catalyst license required). Open, search, create, move, and manage notes from the terminal.

## Source
[slmoloch/obsidian-official-cli-skill](https://github.com/slmoloch/obsidian-official-cli-skill) on GitHub (not available via ClawHub API as of 2026-07-27).

## Prerequisites
- Obsidian 1.12+ with a Catalyst license
- Obsidian must be running for the CLI to work
- CLI enabled via Settings → General → Command line interface
